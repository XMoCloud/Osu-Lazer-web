# Grade artwork

The `GradeSmall-*.svg` badges are unmodified source SVGs from the current
[ppy/osu-web tree](https://github.com/ppy/osu-web/tree/master/public/images/badges/score-ranks-v2019),
retrieved 2026-10-28. Copyright ppy Pty Ltd and osu-web contributors.

The `GradeWhite-*.svg` files adapt the foreground letter paths from those
badges: the capsule, texture and shadow were removed, the viewBox was cropped,
and the letter fill was changed to white. They preserve the reference letter
geometry without distributing a commercial font file. Modified 2026-10-28.

These source SVG files retain osu-web's **GNU AGPL v3** licence. The full licence
is included in [docs/licenses/osu-web-AGPL-3.0.txt](../../docs/licenses/osu-web-AGPL-3.0.txt).
The editable SVG files themselves are the corresponding source for the artwork.
